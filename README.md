## 🚀 О проекте

Библиотека `libgost-rs` предоставляет реализацию российских стандартов блочного шифрования **ГОСТ Р 34.12-2015 (блочные шифры)** с поддержкой режимов работы, описанных в **ГОСТ Р 34.13-2015**.

Основная цель проекта — создание корректной, реализации на Rust для образовательных и практических целей. Код будет постепенно совершенствоваться по мере развития моих навыков программирования на Rust.

## 🔐 Поддерживаемые алгоритмы

### 1. Базовые блочные шифры (ГОСТ Р 34.12–2015)
*   **"Кузнечик" (GOST R 34.12-2015, 128-битный блок)** (`Kuznyechik`) 🦗
    *   Длина блока: 128 бит
    *   Длина ключа: 256 бит
    *   10 раундов преобразования

### 2. Режимы работы (ГОСТ Р 34.13–2015)
Все режимы работают поверх базовых шифров "Кузнечик" или "Магма":
*   **Простая замена (ECB)** ❌ (не поддерживается и не планируется)
*   **Гаммирование (CTR)** ❌ (не поддерживается, планируется к добавлению)
*   **Гаммирование с обратной связью по выходу (OFB)** ❌ (не поддерживается, планируется к добавлению)
*   **Простая замена с зацеплением (CBC)** ✅ (поддерживается, проверен на контрольных примарах)
*   **Гаммирование с обратной связью по шифртексту (CFB)** ❌ (не поддерживается, планируется к добавлению)
*   **Выработка имитовставки (MAC)** ❌ (не поддерживается, планируется к добавлению)

### 3. Сопутствующие алгоритмы (Р 50.1.113–2016)
*   **Формирование ключевой информации**
    *   Алгоритмы HMAC на базе хэш-функций ГОСТ Р 34.11
    *   Функции диверсификации ключей (KDF)
